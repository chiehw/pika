Pika 现在支持在网页中配置探针本机日志监控。Agent 原生读取文件并匹配 Go 正则，命中事件进入现有告警记录和通知模板流程。

- 探针详情新增“日志监控”：路径通配符、正则、告警级别、检查间隔、可选冷却。
- 告警规则新增“日志告警通知”开关，复用既有渠道、维护时段和 JSON 模板。
- 新增 `{{alert.logFile}}` 和 `{{alert.logRuleName}}` 模板变量。
- 文件轮换、截断、半行写入、读取位置持久化和断线重放；服务端按事件 ID 去重。
- 提供 Linux、macOS 服务端完整运行包和 Linux、macOS、Windows Agent 二进制，附 SHA256SUMS。

服务端和 Agent 都需要升级。首次添加规则跳过已有日志；原有通知规则默认不开启日志通知，需在网页中按需开启。

运行包包含管理网页、默认主题、配置示例和 Agent 下载文件。VictoriaMetrics 仍需按配置单独运行。使用说明见 README 和 docs/log-monitor.md。

验证：Go 全量测试、日志监控竞态测试、管理网页与默认主题构建、WebSocket 配置与确认测试、复用现有模板到模拟 Webhook 的集成测试。
