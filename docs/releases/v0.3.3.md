修复 fork 仓库的 Docker 镜像发布工作流。

- 仅 `v*` 版本标签自动触发镜像构建，普通分支提交不构建镜像。
- 发布到当前仓库对应的 GHCR；本仓库为 `ghcr.io/chiehw/pika`。
- 提供 Linux amd64、arm64 镜像，包含管理网页、默认主题和全部 Agent 二进制。
- 生成原始版本标签、语义版本、次版本和正式版本的 `latest`。
- 发布前检查容器启动、管理网页和 Agent 资源。
- Compose 默认使用本仓库的 GHCR 镜像，可通过 `PIKA_VERSION` 固定版本。
- 移除依赖上游仓库名和 Docker Hub 密钥的限制；构建无需 UPX。
